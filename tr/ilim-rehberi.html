Giriş
بِسْمِ ٱللَّٰهِ ٱلرَّحْمَٰنِ ٱلرَّحِيمِ

İslami ilimler, Allah'ın vahyi olan Kur'an-ı Kerim'i anlamak ve hayata tatbik etmek için geliştirilmiş sistemli bilgi alanlarıdır.

Bu rehber, geleneksel ilim geleneğini modern öğrenme metodolojileriyle birleştirerek size yol gösterecek.

"RABBİM, BENİ İLMDE ZİYADE KILIR."

- Taha Suresi, 114. Ayet

Neden İslami İlimler?

  • Kur'an ve Sünnet'e doğru anlayış
  • Günlük ibadetlerde bilinçli uygulama
  • Modern sorulara fıkhi cevaplar
  • İslam medeniyeti mirasını tanıma
Kur'an İlmi
كِتَابٌ أَنزَلْنَاهُ إِلَيْكَ مُبَارَكٌ

Kur'an-ı Kerim, Allah'ın kelamı olarak Müslümanlar için temel kaynaktır. Onu okumak, anlamak ve yaşamak her müminin görevidir.

Kur'an Öğrenme Yöntemleri

📖

Tilavet

Ayete uygun telaffuzla okuma. Tecvid kurallarını öğrenme.

🧠

Tedebbür

Ayetlerin anlamlarını düşünme ve hayatımıza uygular.

📚

Tefsir

Ayetlerin iniş sebeplerini ve yorumlarını çalışma.

Tefsir Usûlü

Tefsir, Kur'an ayetlerinin anlamlarını açıklamak ve yorumlamak için kullanılan ilim dalıdır.

Tefsir Türleri

Tür Açıklama Örnek Eser
Tefsir bi'l-Me'tsur Sahabe ve Tabiin rivayetleriyle açıklama Tefsir Ibnu Kesir
Tefsir bi'l-Ra'y Alimin içtihadıyla açıklama Razi Mefatihu'l-Gayb
Tefsir-i İshari Işıltı/İşaret tefsiri (Tasavvufi) Kurşunoğlu Tefsiri
Önemli: Tefsir çalışırken güvenilir kaynaklardan ve ehil alimlerden faydalanmalısınız.
Hadis Bilgisi
إِنَّما الْأَعْمَالُ بِالنِّيَّاتِ

Hadis, Peygamber Efendimiz'in (s.a.v.) sözleri, fiiller ve takrirlerinden oluşan ikinci temel kaynaktır.

Sahih Hadis Kitapları (Kütüb-i Sitte)

  • Buhari - En sahih hadis koleksiyonu
  • Müslim - Hadis ilminde ikinci otorite
  • Tirmizi - Fıkhi hadisler ağırlıklı
  • Abu Davud - Fıkıh odaklı
  • Nesai - Namaz ve ibadet hadisleri
  • İbn Mace - Kapsamlı koleksiyon
Hadis Sıhhat Kriterleri 
interface HadithCriteria {
    isnad: {
        continuity: boolean;  // Senet bağlantısı kesintisiz mi?
        integrity: boolean;   // Rijal (rivayet edenler) adil mi?
        precision: boolean;   // Hatasız mı?
    };
    matn: {
        noShadh: boolean;     // Shühud (tek başına) değil mi?
        noIllah: boolean;     // Hidden flaw yok mu?
        coherence: boolean;   // Diğer hadislerle uyumlu mu?
    };
}

// Sahih Hadis = ALL conditions true
Fıkıh Temelleri

Fıkıh, İslam hukuku olup ameli (fiili) hükümleri araştırır. Günümüzde en yaygın 4 mezhep:

🟤

Hanefi Mezhebi

İmam Ebu Hanife (ö. 150 H.)

Türkiye, Balkanlar, Orta Asya

🔵

Şafii Mezhebi

İmam Şafii (ö. 204 H.)

G. Asya, Afrika, Doğu Afrika

🟢

Maliki Mezhebi

İmam Malik (ö. 179 H.)

Kuzey Afrika, Batı Afrika

🟣

Hanbeli Mezhebi

İmam Ahmed bin Hanbel (ö. 241 H.)

Suudi Arabistan, Körfez

Ahkâm Türleri

Hüküm Açıklama Örnek
Vacip/Farz Yapılması gerekli, terk edilirse günah 5 vakit namaz, oruç
Mendup/Müstehap Takdir edilir, yapmayan günahkar olmaz Sünnet namazlar, sadaka
Mubah Ne sevap ne günah Normal yemek, içmek
Mekruh Terk edilmesi daha iyi Yemek yerken konuşma
Haram Yapılması yasak, yapan günahkar Zina, içki, faiz
Arapça Gramer
ٱلْعَرَبِيَّةُ لِسَانُ الْقُرْآنِ

Arapça, Kur'an'ın dili olduğundan ilim öğrenmenin temel taşlarından biridir. Gramer (nahiv-sarf) olmadan doğru anlamaya ulaşmak zordur.

Kelimelerin Üç Tipi

İsm (İsim)

Zaman almayan kelime

  • Kitap, okul, öğretmen
  • Kendi başına anlam taşır

Fi'l (Fiil)

Zaman taşıyan kelime

  • Gitti, gelecek, gidiyor
  • Mazi, Müşarret, Muzari

Harf (Edat)

Tam anlamı olmayan kelime

  • 'den', 'için', 'ile'
  • Diğer kelimelerle birlikte anlam kazanır
Arapça Kelime Türleri 
enum WordType {
    ISM,    // İsim (Noun)
    FI_L,   // Fiil (Verb)
    HARF    // Harf (Particle)
}

interface ArabicWord {
    word: string;
    type: WordType;
    tense?: 'Mazi' | 'Mudari' | 'Amr';
    case?: 'Fetha' | 'Damma' | 'Kesra';
}

// Örnek analiz
const sentence = [
    { word: 'ذَهَبَ', type: WordType.FI_L, tense: 'Mazi' },
    { word: 'الطالب', type: WordType.ISM, case: 'Fetha' }
];
// "Öğrenci gitti"
İslam Tarihi

İslam tarihi, Hz. Muhammed'in (s.a.v.) doğuşundan günümüze kadar olan Müslüman medeniyetinin gelişimini kapsar.

Önemli Tarih Dönemleri

570

Peygamberimizin Doğumu

Hz. Muhammed (s.a.v.) Mekke'de dünyaya gelir.

610

İlk Vahiy

Hira Mağarası'nda ilk vahiy iner (Alak Suresi).

622

Hicret

Mekke'den Medine'ye hicret. İslam takviminin başlangıcı.

632

Veda Haccı ve Vefat

Peygamberimizin veda hutbesi ve vefatı.

661-1258

Abbasi Halifeliği

İslam altın çağı, bilim ve kültür merkezi Bağdat.

1453

İstanbul'un Fethi

Fatih Sultan Mehmet İstanbul'u fetheder.

İlerlemenizi Takip Edin

Her bölümü tamamladıkça ilerlemenizi kaydedin. Allah için yapılan her ilmî çalışma sevaptır.
